# Dreaming Stories

Application web statique pour publier des histoires oniriques sur GitHub Pages.
Les histoires sont tirées de rêves expliqués à une IA, qui les rédige.

## Fonctionnalités

- Lecture immersive des histoires (thème cosmique étoilé)
- Interface admin protégée par mot de passe
- Publication directe sur GitHub via l'API (Personal Access Token)
- Support Markdown pour le contenu des histoires
- Import de fichiers `.md`
- Layout responsive : sidebar sur desktop, navigation bas sur mobile

## Utilisation

Le site est entièrement statique et hébergé sur [GitHub Pages](https://auremoo.github.io/dreaming-stories/).

L'administration est accessible via `admin.html` (mot de passe requis).
