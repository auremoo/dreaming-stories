Publier les histoires

Les histoires sont sauvegardées localement dans votre navigateur. Pour les rendre visibles à tous les visiteurs, exportez le JSON et mettez à jour le fichier data/stories.json dans votre dépôt GitHub.

  1. 1 Cliquez sur "Exporter le JSON" et copiez le contenu
  2. 2 Allez sur GitHub → votre dépôt → fichier data/stories.json
  3. 3 Éditez le fichier (icône crayon) et remplacez tout le contenu par le JSON copié
  4. 4 "Commit changes" — les histoires sont en ligne en quelques secondes !
